# 바나나 원정대 ver.2

학생용 정적 웹 게임입니다.

- 게임: https://Lhn2221.github.io/banana-orchard-game/
- 수정 가능한 소스: [source-ver2.zip](./source-ver2.zip)
- 출처: [ASSET_CREDITS.md](./ASSET_CREDITS.md)

소스 ZIP을 풀고 npm ci → npm run dev로 실행합니다. 수정 후 npm run build, node scripts/package-web.mjs를 실행하여 .cache/web-upload의 배포 파일을 갱신합니다. 이 저장소의 루트 파일들은 빌드 산출물입니다.
